# Tuners do Oeste — Livro de Manutenções

Pacote HTML completo, desktop-first, para o projeto Fiat Punto Evo 1.3 Multijet 95cv — Trovão de Prata.

## Funcionalidades
- Livro de manutenções.
- Novo registo.
- Modo de edição ON/OFF.
- Editar registos com ícone de lápis.
- Apagar registos com ícone de lixo.
- Projeto Fiat editável.
- Link direto para Instagram.
- Estatísticas.
- Exportar/importar backup JSON.
- Apagar todos os registos.
- Dados guardados no `localStorage` do navegador.
- Imagens do logótipo e do Trovão de Prata incluídas.
- Layout orientado para computador/desktop.

## Abrir no computador
Abra `index.html` no navegador.

## GitHub Pages
1. Crie um repositório no GitHub.
2. Envie todos os ficheiros e a pasta `assets`.
3. Vá a Settings > Pages.
4. Escolha Deploy from a branch.
5. Selecione `main` e `/ (root)`.
6. Guarde.

Não é necessário Node.js, PHP ou base de dados.
